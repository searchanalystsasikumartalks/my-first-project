# Fair Meeting Time Rotator

Open index.html directly in a modern browser, or serve this folder with `python -m http.server 8000`. No build or dependencies. Run `node test.cjs` for logic tests. Upload the folder contents to any static host; nothing has been deployed.

All data stays in browser memory. No analytics, requests, storage, or third-party dependencies. Example values are illustrative. Before public release set a canonical URL and social preview image for your actual domain, and test with target browsers and assistive technology.

## Validation
Node logic assertions and JavaScript syntax checks passed. Browser UI smoke test was attempted but Chromium could not launch because the execution environment blocks its required socket operation. Visual, keyboard and screen-reader QA remain to be run in a browser.
